# 🚓 Police Chase Game

*[🇹🇷 Türkçe versiyonu için aşağı kaydırın / Scroll down for Turkish version]*

An action-packed top-down police pursuit and survival game developed for mobile platforms using Unity 3D and the Universal Render Pipeline (URP) as part of an internship project.

## 🌟 Key Features

* **🏎️ Advanced Vehicle Physics:** Mobile-optimized drift mechanics, handbrake maneuvers, and speed-sensitive steering sensitivity delivering a smooth driving experience.
* **🚁 Smart Police Helicopter & Spike Strip Mechanics:** Advanced AI that predicts the player's movement vector (`linearVelocity`), locks onto their trajectory, performs cinematic dive attacks (attack runs), and drops spike strips onto the road. Includes an automatic building detection system (via Raycast) to prevent obstacle clipping.
* **🚓 Dynamic Police AI:** Pursuit vehicles featuring collision-count mechanics, barricade deployment, and realistic physics interactions with shockwaves and obstacles.
* **🛡️ Abilities & Health System:** Collectible speed boosts, damage-blocking shields, and a dynamic health/damage management pipeline.
* **📱 Mobile Integration:** Built with Unity's New Input System, fully customized for mobile touch controls.

## 🛠️ Tech Stack & Architecture

* **Game Engine:** Unity 6.5 (Universal Render Pipeline - URP)
* **Programming Language:** C#
* **Version Control:** Git & GitHub
* **Architecture & Design Patterns:** Object Pooling (Spike strips & VFX pools), Scriptable Objects (`CarData`), Event-Driven UI Architecture (Action delegates).

# 🚓 Police Chase Game (Türkçe)

Mobil platformlar için Unity 3D ve Universal Render Pipeline (URP) kullanılarak bir staj projesi kapsamında geliştirilmiş, aksiyon dolu, yukarıdan aşağıya (top-down) görünümlü bir polis kovalamaca ve hayatta kalma oyunu.

## 🌟 Öne Çıkan Özellikler

* **🏎️ Gelişmiş Araç Fizikleri:** Mobil cihazlar için optimize edilmiş drift mekanikleri, el freni manevraları ve hıza duyarlı direksiyon hassasiyeti ile akıcı bir sürüş deneyimi.
* **🚁 Akıllı Polis Helikopteri ve Kapan Mekaniği:** Oyuncunun fiziksel hareket vektörünü (`linearVelocity`) tahmin eden, rotasına kilitlenen, sinematik dalışlar (attack runs) yapan ve yola kapan (spike strip) bırakan gelişmiş yapay zeka. Helikopterin binaların içinden geçmesini önleyen otomatik bina algılama sistemi (Raycast ile) içerir.
* **🚓 Dinamik Polis Yapay Zekası:** Belirli çarpışma haklarına sahip, barikat kurabilen ve şok dalgaları ile engellerle gerçekçi fiziksel etkileşimler sunan takip araçları.
* **🛡️ Yetenek ve Sağlık Sistemi:** Harita üzerinden toplanabilen hızlandırıcılar (speed boost), hasar engelleyici kalkanlar (shield) ve dinamik bir can/hasar yönetim sistemi.
* **📱 Mobil Entegrasyon:** Unity'nin Yeni Input Sistemi (New Input System) ile oluşturulmuş, dokunmatik ekranlara tam uyumlu mobil kontroller.

## 🛠️ Kullanılan Teknolojiler ve Mimari

* **Oyun Motoru:** Unity 6.5 (Universal Render Pipeline - URP)
* **Programlama Dili:** C#
* **Versiyon Kontrolü:** Git & GitHub
* **Mimari ve Tasarım Kalıpları:** Object Pooling (Kapan ve efekt havuzları), Scriptable Objects (`CarData`), Olay Güdümlü (Event-Driven) UI Mimarisi (Action delegates).
